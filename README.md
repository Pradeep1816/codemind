# CodeMind

  CodeMind is a full-stack code-intelligence platform that transforms Git
  repositories into structured and searchable knowledge.

  It indexes source code, extracts symbols and dependencies, identifies business
  rules and workflows, and provides source-grounded repository search.

  ## Source Code

  - [Frontend — Next.js](https://github.com/Pradeep1816/codemind-web)
  - [Backend API — NestJS](https://github.com/Pradeep1816/codemind-api)

  ## Technology

  - **Frontend:** Next.js, React, TypeScript, Tailwind CSS
  - **Backend:** NestJS, TypeORM, PostgreSQL
  - **Security:** JWT, rotating refresh tokens, Argon2id, RBAC
  - **Processing:** Git integration, background workers, incremental indexing
  - **Testing:** Jest and Supertest


  ## Current Status

  Authentication, repository management, indexing, knowledge extraction, search,
  and the frontend dashboard are implemented.

  The AI/RAG assistant and MCP integration are planned for future development.
